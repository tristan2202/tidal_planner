# Tidal Router

A free, browser-based pre-departure planning tool for the Netherlands +
Germany Wadden Sea: draw a route, and it finds the departure time that
best rides the tidal stream while guaranteeing the boat's draft clears the
bottom the whole way, at the actual water depth the boat would see at the
time it's actually there.

Static HTML/CSS/vanilla JS, no build step, no framework. Two Cloudflare
Pages Functions provide live water-level data (see `DEPLOY.md`) — apart
from those, this is a 100% client-side app.

This directory is the `t17_unified_app` milestone of a larger project;
see `../Claude.md` (one level up, not part of this repo) for the full
project history, architecture rationale, and data-source research.

## Running locally

Requires a local static server (the binary grid files load via `fetch()`,
which browsers block under `file://`):

```
python -m http.server 8000
```

Then open `http://localhost:8000/`. First load takes ~20-30s (fetches
~450 MB of current/depth/water-level grids for the full NL+Germany
domain).

To also test the live-data Cloudflare Functions locally:

```
npm install -g wrangler
wrangler pages dev .
```

## Data files

Most `.js`/`.bin` data files in this directory are generated by the
`extract_*.py` scripts (each script's own docstring explains its data
source and how to re-run it). Six files exceed Cloudflare Pages' 25 MiB
per-file limit and are deliberately excluded from git (see `.gitignore`)
— see `DEPLOY.md` for how they're hosted instead.
